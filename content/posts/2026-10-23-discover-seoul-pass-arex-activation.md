**Your Discover Seoul Pass starts running when you receive its AREX code—even if you never board the train.** Generating that code a day early can use up 24 hours of a 72-hour pass before your sightseeing starts. Wait until you are ready for the pass itself to begin, not merely ready to organize your tickets.

This rule comes from the [official FAQ, “When does the pass become active?”](https://www.discoverseoulpass.com/app/cs/index/faq), checked **October 23, 2026**. It concerns the AREX benefit redeemed through Discover Seoul Pass. Buying a separate ordinary train ticket is a different transaction.

## Which actions start the clock?

The FAQ separates activation from setting up your other travel essentials:

| Action | Starts Discover Seoul Pass validity? |
|---|---|
| Receive an AREX code through the pass | **Yes**, before boarding |
| Use the pass QR for a free partner attraction | **Yes** |
| Use the included K-Limousine airport bus benefit | **Yes** |
| Download or use the included eSIM | **No** |
| Top up or use the Card Pass's transit or prepaid balance | **No** |

Do not request an AREX code as a test. The [AREX partner instructions](https://www.discoverseoulpass.com/app/spot/index/view/41) distinguish three steps: receive the **13-digit code**, exchange it for a train ticket on site, then board. Activation happens at the first step. The page also says the code and train ticket must be used within the pass duration; issuing a code early does not save a ride for any later date.

If the app already shows time counting down unexpectedly, save the displayed status and contact pass support before planning around a fresh start; do not assume it can be reset.

## One early code can leave only 48 sightseeing hours

The [official Seoul tourism pass guide](https://english.visitseoul.net/tour-pass) describes 72-hour and 120-hour products measured from activation. If AREX activates the pass first, that allowance does not restart when you reach your first attraction.

Here is a **hypothetical 72-hour example**, using Korean local time throughout. Assume no other qualifying service activates the pass earlier, and your first attraction is Tuesday at 09:00.

| First qualifying pass use | Time already used by Tuesday 09:00 | Time left at the first attraction |
|---|---:|---:|
| AREX code Monday 09:00, while preparing for the trip | 24 hours | **48 hours** |
| AREX code Monday 18:00, for your arrival transfer | 15 hours | **57 hours** |
| First attraction Tuesday 09:00; arrival transport paid separately | 0 hours | **72 hours** |

The third row preserves more attraction time but adds a separate arrival-transport expense. It is not automatically cheaper. The calculation is simply **72 minus elapsed hours**; use the app's actual expiry display for the final admission deadline.

The first two rows also show different decisions. Issuing a code before you need it can waste useful time. Using the benefit for an actual evening arrival may be sensible, but you should count the overnight hours when choosing your attraction schedule.

## Decide where the airport journey belongs

For an evening arrival followed by a full sightseeing day, compare these plans before activating:

1. **Use the pass on arrival.** Count the airport ride as a benefit you genuinely need. Put your final must-see attraction inside the resulting expiry window.
2. **Pay separately for arrival transport.** Start the pass later with a qualifying attraction or service. Include the extra transfer cost when deciding whether the longer usable sightseeing window is worth it.
3. **Keep an included transfer for departure.** First confirm that the selected transport benefit and its redemption/use conditions fit your flight day. The AREX partner page requires use within the pass duration, so an AREX ride after expiry needs a separate ticket.

Our [AREX Express versus All-Stop guide](/posts/incheon-airport-arex-guide/) helps with the separate-ticket choice. Pick the airport connection that suits your hotel and luggage; do not add an unwanted trip merely to count another pass benefit.

The pass FAQ lists one one-way AREX Express journey and one one-way K-Limousine 67XX airport-bus journey for the **All-Inclusive Pass**. **Pick 3** uses selected benefits instead. Check your actual pass type and the current partner instructions; the two product families are not interchangeable.

## A transit card and an attraction booking are separate

The [Seoul tourism guide](https://english.visitseoul.net/tour-pass) says the physical Card Pass can be used on subways and city buses **after topping up**. That is not an unlimited subway entitlement. Use our [Climate Card versus T-money comparison](/posts/seoul-climate-card-vs-tmoney/) if ordinary city rides are the main decision.

A running pass also does not confirm a seat on a particular attraction departure. The official FAQ directs users of free attractions with fixed seats or times, such as cruises, to check availability on site that day. Check the partner's instructions before making a particular sailing essential to your plan. Our [Han River cruise guide](/posts/han-river-cruise-seoul-prices-tickets-how-to-book/) separates the pier, reservation and boarding checks.

Before issuing the code, write down four things: **your planned first pass use, the expected expiry, your last essential attraction, and your airport-return plan**. If they do not fit together, change the plan before starting the clock. After intentionally activating, confirm the actual expiry in the app.
